# Автотесты: Live-комнаты PlatformaX

Playwright-набор для задачи «Тестирование live-комнаты»: встречи 1-1 и на группу, видео, чат, управление участниками, запись, доступы.
Тесты ходят в **тестовый стенд** через настоящий интерфейс и API, создают свои комнаты `QA-AT …` и завершают их в конце.

## Запуск (3 шага)
```bash
npm run setup          # Playwright + Chromium
cp .env.example .env   # заполнить адрес стенда и учётки
npm test               # ~6 минут, отчёт: npm run report
```
`npm run test:headed` — то же с видимым браузером. Один тест: `npx playwright test -g "M-6"`.

## Учётки (.env)
- Владелец школы (ведущий).
- Ученик A — **без** продукта `PRODUCT_ID`, ученик B — с ним.
- Сотрудник с правами «только просмотр» (необязательно — тест пропустится).
- QA-режим без паролей учеников: `OWNER_STORAGE_STATE` (сохранённая сессия владельца), ученики входят через «Войти как».
