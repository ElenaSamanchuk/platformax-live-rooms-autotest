# Проверка выгрузок метрик записи

Автономная проверка JSON-ответа списка записей сотрудника. Локальный запуск без браузера, модели, сети и дополнительных зависимостей; нужен Node.js 18 или новее

```sh
node scripts/validate-recording-metrics.mjs /absolute/path/new-recordings.json
node scripts/validate-recording-metrics.mjs /absolute/path/legacy-recordings.json --legacy
```

Ожидается непустой массив `recordings` или массив записей. Для новой готовой записи проверяются ключи `duration_seconds`, `ready_at`, `preparation_seconds`, `size_bytes`, неотрицательные конечные числа и соответствие `ready_at - ended_at` времени подготовки с допуском 1,5 секунды. Опция `--tolerance-seconds=N` меняет допуск

В режиме `--legacy` неизвестные `ready_at` и `preparation_seconds` обязаны оставаться `null`; дата обновления не заменяет момент готовности. Длительность должна быть числом, размер исторической записи может быть `null`

Код выхода: 0 — проверки прошли, 1 — несоответствие данных, 2 — неверный вход/аргументы. Вывод — JSON с проверенными значениями и ошибками

Это проверка предоставленной выгрузки, не живой E2E. Она не запускает встречу, не измеряет среднее по системе, не доказывает повторную обработку, доступ ролей, размер файлов на хранилище или воспроизведение видео. Повторный GET не подтверждает идемпотентность обработки. Данные API, учётки и сессии не добавлять в репозиторий
