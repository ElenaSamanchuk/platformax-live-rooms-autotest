## Воспроизводимость

Новые тесты запускались в изолированной копии `git archive HEAD` с коммитнутым `tests/helpers.js`. Его содержимое побайтно совпало с `git show HEAD:tests/helpers.js`. Чужие незакоммиченные изменения helpers и других тестов не использовались при подтверждении результата и не включены в публикацию.

Версия установленного Playwright 1.63.0 зафиксирована в `package.json` и `package-lock.json`. После клонирования, установки зависимостей и настройки `.env` обычные команды:

```bash
npm test
npm run test:known
```

Для email/CSV требуется `QA_STUDENT_EMAIL` существующего тестового пользователя. `QA_STUDENT_ID` позволяет дополнительно проверить его ID. Без email только этот сценарий пропускается с явной причиной. В выполненном локальном запуске оба параметра были заданы.

### Фактически выполненные повторные команды

Полный запуск четырёх ключевых сценариев на коммитнутых helpers:

```bash
QA_OUT=qa-out/codex-1023-final \
npx playwright test --config=qa-out/clean-head-source/playwright.config.js \
  current-smoke.spec.js --output=test-results-codex-1023-final
```

Итог: H-2, восстановление гостя и L-21 прошли. Основной сценарий получил сетевой `ERR_TIMED_OUT` при ожидании полного `load` приглашения. Для гостевых переходов выбрано ожидание `domcontentloaded`, затем повторён только затронутый сценарий вместе с новым тестом формы:

```bash
QA_OUT=qa-out/codex-1023-targeted \
npx playwright test --config=qa-out/clean-head-source/playwright.config.js \
  current-smoke.spec.js access-email.spec.js -g 'Основной сценарий|Доступ:' \
  --output=test-results-codex-1023-targeted
```

Основной сценарий прошёл. Email/CSV прошёл деловые проверки, но упал на ошибочном требовании завершить ещё не начатый draft. Исправлена только очистка: свой неопубликованный private/draft сохраняется с нулём участников. Финальная команда:

```bash

npx playwright test --config=qa-out/clean-head-source/playwright.config.js \
  access-email.spec.js known-issues.spec.js \
  --output=test-results-codex-1023-email-known-final
```

Итог: email/CSV — 1 PASS; строгая L-22 — 1 FAIL на требовании отдельной вкладки. Красный результат не замаскирован через `skip`, `test.fail` или обратное ожидание текущего поведения.

`qa-out/clean-head-source` — локальная копия `git archive HEAD` с добавленными новыми тестами. Она и персональная конфигурация не публикуются. Полученный коммит содержит необходимые исходники для обычного запуска без этого служебного каталога.

## Точный замер L-17

После удаления гостя через UI кнопка проверялась **до** нового входа или запроса `guest/join`:

- Комната 362: во всех 12 наблюдениях от 1 до 5661 мс кнопка входа активна.
- Комната 365: во всех 12 наблюдениях от 0 до 5614 мс кнопка также активна.
- После отдельного `guest/join` сервер возвращает 403, кнопка становится неактивной с текстом Вход закрыт.
- Затем ведущий возвращает доступ через UI, прежнее приглашение снова пускает гостя.

Зелёный сценарий подтверждает серверную блокировку и штатное восстановление. Естественное обновление кнопки за наблюдавшиеся 6 секунд не исправлено. Факты каждого запуска сохраняют последовательность и время измерения.
