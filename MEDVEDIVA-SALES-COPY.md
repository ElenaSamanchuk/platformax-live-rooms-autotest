# Medvediva: текст продажи и остаток между потоками

Решение продукта от 29.10.2026: техническая возможность использовать остаток при непрерывном продлении не афишируется в информации продаж. L-MDV-22 сохраняет это ожидание и остаётся красным, пока касса обещает следующий поток

## Живая проверка без оплаты

`tests/medvediva-sales-copy.spec.js` только читает кассу. Все запросы записи заблокированы. Кнопка оплаты не нажимается. Нужна независимая студенческая сессия, без Войти как

В локальном `.env` задайте `MEDVEDIVA_BASE_URL`, `BRAND_QA_ALLOWED_ORIGINS`, `MEDVEDIVA_STUDENT_STORAGE_STATE`, `MEDVEDIVA_STUDENT_USER_ID`, `MEDVEDIVA_QA_CHECKOUT_PATH`, `MEDVEDIVA_QA_PACKAGE_NAME`. Путь должен вести к собственной QA-услуге со сроком поток покупки + 1; имя пакета начинается с QA. Секреты, значения переменных и снимки данных не коммитить

```sh
npx playwright test tests/medvediva-sales-copy.spec.js --reporter=list --output=test-results-medvediva-sales-copy
```

Без сессии или фикстуры результат NOTRUN, не PASS. Проверяются конкретные запрещённые формулировки о следующем потоке и остатке при продлении, а не смысл любых возможных текстов. Тест не проверяет сам перенос, покупку, расчёт срока или сгорание

## Проверка сохранённого текста без браузера и ИИ

Сохраните видимый текст кассы в локальный UTF-8 TXT без личных данных и адресов. Скрипт не выводит его содержимое

```sh
node scripts/check-medvediva-sales-copy.cjs /absolute/path/to/visible-sales-copy.txt
```

Код завершения: 0 — этот снимок соответствует правилу, 1 — найдено нарушение L-MDV-22, 2 — входные данные не позволяют провести проверку. Снимок не является новой проверкой сервера: после выкладки нужен свежий снимок или живая проверка выше
